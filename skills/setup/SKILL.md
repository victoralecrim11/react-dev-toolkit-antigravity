# Setup

Configura ambiente e perfil. Copie arquivos de `./skills/react-dev/references/project-hub/` para `<pasta-base>/ProjectHub/`. Suba o servidor a partir de la. Use `POST /api/config` para merge parcial. Garanta a presenca das configuracoes de TypeScript estrito (`rules/typescript-estrito.md`) e mapeamento inicial de tokens de UI/UX em `./skills/ui-ux/data/`.
