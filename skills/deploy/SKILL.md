# Deploy

Siga `./skills/react-dev/references/deploy-advisor.md`. Analise a stack, valide o build e publique.
Escolha o provedor com base nas restricoes (Vercel, Netlify, Cloudflare Pages ou Expo EAS). 
Use o MCP da Vercel configurado em `mcp_config.json` quando a stack for Next.js e o MCP estiver disponivel
