# UI/UX Pro Max Engine

Esta skill atua como autoridade em design de interfaces, fornecendo direcionamento visual, paletas de cores, tipografia, guidelines de UX e acessibilidade antes da implementação técnica.

## Fluxo de Integração
1. **Descoberta do Produto:** Identifica nicho, público-alvo e objetivo de negócio a partir de `data/products.csv`.
2. **Definição de Estilo:** Seleciona a melhor linguagem visual (Minimalista, Brutalista, Neumorfismo, Glassmorfismo, Clean SaaS, Dark Mode Pro) consultando `data/styles.csv`.
3. **Harmonia Cromática e Tipográfica:** Determina paletas semânticas acessíveis (contraste WCAG AAA/AA) a partir de `data/colors.csv` e fontes em `data/typography.csv`.
4. **UX & Acessibilidade:** Aplica regras de usabilidade, hierarquia de CTA e estados de interação com base em `data/ux-guidelines.csv` e `references/accessibility.md`.
5. **Handoff Técnico:** Transmite os tokens de design para o `react-dev` estruturar styled-components, Tailwind CSS, shadcn/ui ou React Native StyleSheet.
